# fman - Two Paths You Read Before You Copy

At a glance:
- Two panes with paths you can read
- A jump to a folder you name
- A one-file copy before the rest
- Plugins only after you have read them

## The Destination Pane

fman is a dual-pane file manager. The focused side is the one that receives the drop or the command. Click the destination and read the path, including the drive letter, before you copy. Similar folder names on two disks are how a project lands on the wrong drive. A jump you typed is only as good as the path. If the letter is stale after you replugged a stick, jump again.

Explorer can still open the same folders. Use it to confirm the test file arrived. fman does not replace the files with a private format. They stay ordinary files.

## Copy, Then Move

Copy a small file first. Open it from the destination pane. If it opens, the path is the one you meant. A move deletes the source. Use move only when the copy test has already worked and you mean to empty the source. Do not run a move on the only copy of a folder you have not backed up.

A filter or a hidden-extension view can make two files look identical. Turn extensions on while you copy. Do not launch an installer from a preview because the pane made it easy.

## Plugins Are Code

fman can run Python plugins. A plugin can rename, upload, or delete. That is a program. Read it. Do not install a plugin from a gist you have not read. The default two panes are enough. A plugin that asks for a password to a server is a server you must already be allowed to use. If the host is wrong, do not try other accounts.

## Drive Letters

Before a copy to removable media, confirm the letter in the pane matches the disk in your hand. Unplug extras if the list is confusing. After you eject, do not reuse the old path. The next stick may receive that letter. Close the pane or jump to the new path after you refresh the disks.

## Leave System Folders

Windows, Program Files, and another user's profile are not working panes. If you opened one by a jump, close it without copying and without deleting. A rename there can stop a program from starting. Practice on a folder you created.

## Shared Desk

Close fman when you leave. A pane can show private filenames. A plugin that stored a password would remain for the next login. Do not save credentials in a plugin on a shared PC. The files you copied remain in the destination. The manager does not need to stay open.

## Installation Path

| Step | Action |
|---|---|
| 1 | Install fman and open a source folder and a destination folder you own |
| 2 | Read both paths and the drive letters |
| 3 | Copy one small file into the destination |
| 4 | Open that file from the destination pane |
| 5 | Copy the rest only if it opened. Leave plugins off until you have read them |

## Player Profile

fman fits a copy between two folders you can explain. It does not fit system directories, another person's files, an unread plugin, or a move of the only copy before a test file has opened.

## Help Desk

The file landed on the wrong disk? The letter in the pane was not the stick you held. Put the file back and read the path.
A move emptied the source? Restore from the destination or from backup. Copy next time until you mean to move.
A plugin did something you did not expect? Disable it. It ran the code you enabled.
Extensions look hidden? Turn them on before the next copy.
You opened Windows? Close the pane without deleting anything.

## Reader Notes

Two paths, one small file, one open from the destination. That is the whole safety check. The rest of the copy is the same gesture with more files, still watching the letter.

Plugins wait until the panes are familiar. They are programs. A dual pane does not make them safe. Read them or do not add them.

Eject the stick and do not trust yesterday's letter. Jump again after the disk is mounted. Close the window on a shared desk so the filenames are not the next person's first view.
